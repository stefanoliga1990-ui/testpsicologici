# Documentazione dei questionari

- `audit-psicometrico-2026-08.md` descrive l'audit trasversale e lo stato corrente dei 15 questionari.
- `standard-psicometrico.md` definisce il processo obbligatorio per revisioni e nuovi questionari.
- I file `analisi-test-*-v1.json`, `test-autismo-v2.md`, `test-adhd-v2.md` e `test-ocd-v1.md` sono specifiche storiche delle versioni indicate nel nome. Restano nel repository per tracciabilità e non descrivono necessariamente soglie, ancore o ordine di somministrazione correnti.

Il codice e i test automatici sono la fonte operativa per la versione pubblicata. Qualunque nuova versione deve aggiornare anche l'audit o aggiungere una specifica di revisione equivalente.
